# WChem Backend Upgrade — 2026-07-30

## What changed

### 1. leaderboard unique constraint (migration 20260730053339)
- Added `period_start timestamptz` to `public.leaderboard`.
- Old constraint `UNIQUE(user_id, period)` — **dropped**.
- New constraint `UNIQUE(user_id, period, period_start)`.
- `refresh_leaderboard(p_period)` now upserts against `(user_id, period, period_start)`:
  - `weekly` → Monday 00:00 of current week
  - `daily`  → today 00:00
  - `all_time` → epoch
- `UPDATE public.leaderboard` backfill ran; existing rows now have non-null `period_start`.
